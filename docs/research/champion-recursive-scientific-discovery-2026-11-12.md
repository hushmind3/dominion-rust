# 챔피온 — 자가 진화하는 재귀적 과학자 (2026-11-12)

## 심판 피드백을 구조적으로 반영

2026-11-12 심판 피드백: 챔피온 69점, 서브3 73점, 서브4 71점. 기존 챔피온은 상호개선·학습·후손 실행을 통합했으나 후손이 과학적 실험 방법을 바꾸고 **새로운 지능 구성요소를 발명해 역방향 재개선까지 실행하는 독립적인 메커니즘**이 약했다.

여기서 도입한 메커니즘은 다른 브랜치의 기능을 단순 합산하는 모듈 모음이 아니라, **독립 결과를 관찰하는 방법 → 개입을 설계하는 방법 → 지능을 발명하는 방법 → 발명된 후손의 원래 지능 재개선 → 과학적 개선 방법의 자기 재작성**이 한 계보에서 순환하는 소스 실행 정책이다.

## 실제 통합 경로

1. **참조 기반 비교**: `rsi_factorial.rs`는 서브3의 요인분리 구현을, `rsi_open_topology.rs`는 서브4의 개방형 진화 구조를 비교·도입했다. 원 저작 브랜치의 개별 구조와 구분해 아래 자체 개발을 추가했다.
2. **독자적인 후손 재귀 과학자**: `rsi_recursive_scientist.rs`가 요인분리 누락 → 동일 동결 조건의 대비 학습 → 새로운 과학적 실험 기법 또는 지능 구성요소 발명 → 발명한 지능의 다음 후손 개선 → 원래 지능 재개선 → 실험 선택기 자체 수정의 다음 단계와 소스 파일을 선택한다.
3. **실패 기반 실험 방법 변화**: 실제 모델 코드 후보의 독립 채택/반려 기록에서 실험 종류별 생산성을 추정한다. 동일 실험 방법이 여러 실제 후보에서 실패하면 새로운 실험 및 메커니즘 발명으로 전환한다.
4. **실제 신규 지능 생성 계약**: `rsi_system::propose` + `tools.rs` `rsi_system_plan.newComponents`는 새 역할 이름, 발명 목적, 구현 소스, 실행 연결 소스, 개선할 기존 지능을 함께 요구한다. 실행 파일에 들어가지 않는 새 파일은 새로운 지능의 탄생으로 인정하지 않는다.
5. **개방형 후손 자기모형**: `rsi_system::blueprint`는 독립 채택 및 연결 근거가 있는 새로운 소스 역할을 다음 세대의 설계/선택 대상으로 재등록한다. `scientific_method`, `experimental_design`도 별도 수정 가능한 역할이다.
6. **실제 후손 실행 연결**: `rsi_evolve.rs`의 재컴파일된 후손 계획, 외부 소스·해시 검증, 작업 대상 편집 우선순위, 모델 입력 문맥, 세대 실행 기록, 후손의 계산 재검증 경로 모두 이 프로그램을 전달한다. 격리 실험은 집중 편집 소스 1개를 선택한다.
7. **세대 간 진짜 계승**: 발명 → 후손 개선 → 원래 지능 재개선 → 과학자 재작성은 실제 `acceptedCommit` → `generatorCommit` 연결과 수정 소스·독립 평가가 일치한 경우에만 진행한다. 중간에 다른 유효한 구성요소 수정이 채택돼도 실제 계보를 따라 계획을 유지한다.
8. **채점과 증거 분리**: 이 구현은 구조의 잠재적인 재귀순환 경로다. 독립 평가에서 실제 성능을 증명하거나 80점을 획득했다고 선언하지 않는다.

## 논문과 공개 구현에서 채택한 원리

- [HyperAgents (2026)](https://arxiv.org/abs/2603.19461) / [공개 코드](https://github.com/facebookresearch/HyperAgents): 작업 지능과 개선 지능을 함께 수정 가능한 소스로 만든다.

- [Mendel Gödel Machine (2026)](https://arxiv.org/abs/2608.07645): 여러 후손과 실험 계보의 결과를 비교해 다음 소스 개발 방법을 바꾼다.

## 단위 테스트 계약

`rsi_factorial.rs`: 동일 기준의 격리/합동 실험, 무근거 인과 주장을 인정하지 않음.

`rsi_open_topology.rs`: 새 역할의 실제 컴파일 소스와 런타임 연결 없이 신규 지능 계승 불허.

`rsi_recursive_scientist.rs`: 새 지능 발명 제안, 격리 실험의 단일 편집 소스, 실재하는 자식의 재귀 귀환, 증거 없는 발명의 차단, 반복 실패에서 실험 방법 변화, 과학적 평가 계획 해시 변경 방어.

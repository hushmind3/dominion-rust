**문맥 재사용 결함은 수정했다. 짧은 실제 비교에서 신규 입력이 줄었지만, 매턴의 높은 신규 입력 비용과 자동 학습을 포함한 전체 비용 문제는 해결 완료가 아니다.**

## 수정한 경로

- 검색 결과를 묶음 ID 대신 개별 자료의 종류·ID로 관리한다. `[A] → [A,B]` 선택 시 A를 다시 덧붙이지 않는다. 빈 메타데이터만 제거하고 원문·출처·검증 정보는 보존한다.
- 기억과 방 지식의 중요도·확신도 등 점수 갱신을 내용 수정으로 취급하지 않는다. 내용·출처·공개 범위·폐기·정정 변화는 계속 무효화한다.
- 질문마다 선택하는 주인 확정 상태를 필수 문맥으로 유지하되, 고정 페르소나 앞부분을 다시 쓰지 않는다. 주인 정정 시 이전 상태를 무효화한다.
- Codex WebSocket에도 HTTP와 동일한 캐시 키를 전달한다. 명시적으로 거부되면 해당 힌트를 비활성화하고 HTTP로 복구한다. 부분 응답 이후에는 재시도하지 않는다. 힌트 수락은 캐시 적중 증거가 아니다.
- 이전 묶음 형식의 작업 문맥은 업그레이드 시 한 번 갱신한다. 매턴 초기화하지 않는다.
- 공통 지침을 축약한 초기 안은 제외했다. 최종안은 기존 공통 지침·9명·개별 페르소나·대화 원문을 유지한다.

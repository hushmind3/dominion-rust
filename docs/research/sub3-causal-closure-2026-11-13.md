# 서브3 — 독립 인과 폐회로 검증 설계 (2026-11-13)

## 구현과 실행 경로
`rsi_evolve::run_loop`는 세대마다 SHA로 검증된 Rust 실행 바이너리를 보존하고, 다음 재컴파일 버전이 독립적으로 채택된 뒤 동일한 입력 소스·작업·DB 계보를 이전 개선기 바이너리에도 전달해 **무모델 계획 비교**를 수행하도록 변경했다. 실제 worker는 현재 바이너리의 정식 계획만 사용한다. 버전 문자열 차이만으로 행동 변화를 인정하지 않는다.

`rsi_causal_closure::audit`는 실제 반영된 계획과 소스 편집 경로, 독립 A/B 원본의 재생 영수증을 결합한다. 4개 채택 세대를 요구한다: 메타 개선 채택 → 다음 후손의 새로운 기능 개선 → 다음 메타 개선 채택 → 재컴파일된 메타 개선기로 다시 기능 개선 채택. 연속된 후손마다 matched compiled planner 비교를 남기고, 특히 두 차례 메타 개선 이후의 실제 실효 계획이 달라져야 하며, 실제 변경 경로와 해당 계획이 이어져야 한다. 메타 2건과 기능 2건의 독립 홀드아웃 성과까지 확인했을 때만 `demonstrated` 가 될 수 있다.

기존 `handoff_evidence`의 구조적 계승 증거는 유지하고, 새로운 인과 폐회로 증거를 `causalClosure` 필드로 분리해 사용자와 심판이 언제 0/45 구간을 벗어날 수 있는지 확인 가능하게 했다.

## 검증 상태
현재 새 실행 결과를 만들지 않았고, 테스트·컴파일·빌드·벤치마크·유료 모델 호출은 수행하지 않았다. 실제 반복 지능 향상이 입증됐다는 뜻이 아니다. 재검증에서 후손 소스·실효 계획·독립 평가 영수증을 확인해야 한다.

# 서브3 — 독립 평가로 개선 원리 자체를 학습하는 후손 재귀순환

**기준:** 2026-11-13 · 심판 재판정 서브3 72점, 챔피온 74점 · CI 실행 여부는 구조 점수에 반영하지 않음.

## 왜 기존 코드가 72점에 머물렀는가

기존 서브3의 `rsi_program_graph.rs`는 모델이 발명한 노드와 조건부 전이를 실제 컴파일된 후손이 사용할 수 있게 했다. 그러나 전이의 초기 의사결정은 `adopted/improved/neutral/regressed`와 미리 정한 분기 우선순위에 치중했다. **소스 채택**과 **그 개선 방법이 실제 작업을 더 잘 해결하게 만든 것**이 충분히 구분되지 않았고, 서로 다른 지능 구성요소에서 얻은 개선 경험을 새로운 개선 원리로 학습하는 단계가 약했다.

이번 구현은 고정된 재귀 단계를 더 만드는 대신 **측정값 → 원리 학습 → 프로그램 선택 및 합성 → 독립 평가 → 후손 생산성 측정 → 학습기 자체 재설계**를 실제 제어 경로에 연결한다.

## 실제 추가한 구성요소

### `src/engine/rsi_principle_learning.rs` — 재컴파일 후손에 속한 개선 원리 학습기

- 독립 평가 대상의 `candidateId`, `generatorCommit`, `changedSourcePaths`, `evaluationProfileSha256`, `compiledPlanExecuted`를 기준으로 분석한다.
- 단순 채택 수와 다른 `holdout`별 `baselinePass/candidatePass` 또는 명시적 `quality` 변화만 학습한다. 회귀 및 중립 결과도 손실 신호로 남긴다.
- 열린 프로그램 노드의 `mechanism`과 종전 일반 `systemDesign.hypothesis`를 모두 학습 원리로 취급한다. 원문은 가설/범주 식별자일 뿐 **성과를 증명하지 않는다**.
- 한 세대가 개선된 후 **다른 컴파일된 후손이 모델·기억·학습·하네스·도구 등을 별도 개선 방법으로 수정**할 경우, 그 후손의 독립 평가에서 실제 작업 개선이 발생한 결과를 선행 개선 원리의 후속 생산성으로 별도 측정한다. 부모/후손의 직접 인과 효과는 주장하지 않는다.
- Beta(1,1) 수축 사전분포를 사용하는 `posteriorCaseGain`과 `posteriorDescendantGain`, 회귀 벌점, 미측정 탐색 보너스를 계산한다. 추정식 자체가 이 모듈의 평범한 가변 Rust 소스이며 후손이 교체할 수 있다.
- `predictiveCalibration`은 **평가 전에 사용된 예측값**과 나중에 수집된 실제 과제 결과를 비교해 Brier 오차를 축적한다. 독립 측정이 충분하고 오차가 높을 때, 새로운 가설/그래프만 반복하지 않고 `rsi_principle_learning.rs`의 알고리즘을 후손이 수정할 대상으로 삼는다.
- `principleKeys`: 모델이 서로 다른 개선 프로그램에 공통으로 붙인 가변 원리 키. **서로 다른 2개 이상의 실제 측정된 메커니즘**에서 동일 키가 유효했던 경우에만 새로운 메커니즘으로 학습된 우선순위를 전이한다. 성과가 없는 태그는 사전확률 이상으로 승격되지 않는다.
- 학습 결과에는 `modelWeightsTrained:false`, `causalAttributionProven:false` 등을 남긴다. **모델 파라미터 미세조정 자체는 아직 구현·실행하지 않았다.** 현재 구현의 모델 개선은 모델 실행/선택/컨텍스트/학습 경로의 소스 수정과 다음 후손의 실제 과제 평가를 대상으로 한다.

### `src/engine/rsi_program_graph.rs` — 임의 그래프의 실제 선택 알고리즘 학습

- 기존 **알파벳 노드 우선순위**가 아니라 독립 검증된 원리별 실제 과제 성과·회귀·후손 생산성에 따라 서로 가능한 다음 개선 노드를 순위화한다.
- 조건부 전이 그래프는 모델이 작성하고 새 소스가 독립 채택되면 다음 후손이 교체할 수 있다. 전이의 품질 예측은 `principleLearningSha256`, `principleSelectionEvidence`로 계획과 실행 내역에 결합한다.
- `principleKeys`는 새 프로그램 노드에서 선택 사항이다. 실제 측정된 원리의 조합을 바탕으로 새 원리의 탐색 우선순위를 조정한다. 복제한 설명이나 텍스트 유사성만으로 성공을 생성하지 않는다.

### `src/engine/rsi_meta_controller.rs` — 전체 지능 목표와 개선 학습 연결

- 모델·학습·기억·도구를 포함한 소스 후보를 평가할 때, 과거 독립 검증된 **실제 과제 개선** 및 **다음 후손의 다른 역할에 대한 실제 과제 개선**을 메타 선택 점수에 더한다.
- `steer_learner_repair`는 이미 측정된 자기 예측 오류가 커졌을 때 `rsi_principle_learning.rs`의 재설계를 후속 작업으로 지정한다. 가변 그래프/실제 진행 중인 정당한 후속 개선 단계는 보존한다.

### `src/engine/rsi_evolve.rs` — 학습 내용이 실제 실행으로 이동하는 경계

- 재컴파일된 `plan_generation_from_file` 내부에서 개선 원리 학습 장부를 만들고 `principleLearning`으로 출력한다.
- 감독자/worker에서 장부를 다시 검증하고 `rsiPrincipleLearning`으로 전달한다. `compiledPlanExecuted.principleLedgerSha256`, `rsi_generation.principleLearning`에도 계승한다.
- `rsi::replayed_pair_metrics`를 사용하여 후보 원본의 독립 평가 기록을 다시 재생한다. 모델이 만든 성과 요약이나 다른 패치의 증거를 학습 원리로 둔갑시키면 다음 세대 진입을 거부한다.
- 기본 평가 프로필을 쓰는 세대도 `rsi_profile::from_input`으로 **실제 동결 평가 프로필 SHA**를 기록한다. null 프로필 해시 때문에 학습 자료가 사라지는 경로를 차단한다.
- worker 모델 프롬프트에 실제 학습 장부의 상위 원리, 회귀 및 전이 증거, 예측 오차와 원리 재구성 권고를 주입한다. 사용자 지정 작업 및 동결 평가 소스는 침범하지 않는다.

### `src/engine/rsi_system.rs` — RSI 완성도 허위 주장 강화

- 프로그램의 독립 채택 기록과 별개로 `independentlyImprovedTaskCases`, `independentlyImprovedDescendantCases`, `independentlySupportedTransferablePrinciples`, `learnedPrincipleLedgerSha256`를 보고한다.
- `capabilityDemonstrated`는 기존 3세대 채택 조건 외에 **다른 역할의 실제 후손 과제 개선**과 **실제 실행된 개선 프로그램 자체의 수정**을 요구한다.
- 새로운 모델 학습 또는 지능 완주로 오인될 수 있는 계획·태그·소스 수정 수 자체는 성공 지표로 승격하지 않는다.

## 반증 테스트

- 독립 평가로 실제 개선된 메커니즘이 측정상 중립·회귀 메커니즘보다 우선된다.
- 새 후손이 완전히 다른 방법으로 **모델 실행 소스**를 개선한 평가도 선행 원리의 전이 측정에 포함된다.
- 원래 개선 그래프의 두 후속 분기를 동일한 조건으로 열고, 독립 평가에서 더 유효한 원리를 선택한다.
- 두 개의 서로 다른 독립 평가 메커니즘에서 공유된 원리 키가 새 메커니즘의 사전 추정을 바꾸며, 증거가 없으면 기본 사전값에 머문다.
- 중립적인 패치의 소스 채택은 실제 작업 개선으로 학습하지 않는다.
- 모델의 자기보고, 다른 평가 원본, 틀린 소스 커밋, 수정 경로 불일치, 원본 후보 영수증 미재현은 학습 증거가 될 수 없다.
- 실제 독립 평가에 대한 예측 실패가 누적되면 다음 학습 알고리즘 수정 대상으로 연결된다.

테스트 함수들은 저장소에 반영되어 있다. **Rust 컴파일·단위 테스트 실행·CI·장기 RSI 완주 자체는 하지 않았다.** 실행하지 않은 성능 개선을 주장하지 않는다.

## 2026년 외부 근거 및 경쟁 코드

- [MetaExp / 2026-10](https://arxiv.org/abs/2610.21492): 여러 과제 사이에서 재사용할 수 있는 경험의 학습을 실제 모델 능력으로 학습·평가.
- [Meta^n / 2026-08](https://arxiv.org/abs/2608.24735): 고정 깊이 아닌 누적 궤적·상위 전략을 지속적으로 만드는 후손 계층.
- 경쟁 챔피온 최신 `rsi_method_generalization.rs`는 평가 원본 재생과 후손 결과 학습이 강점이다. 서브3는 그 원본 재생을 계승하면서 **모델 저술형 열린 그래프, 다른 후손 개선 방법까지 포괄하는 생산성 학습, 가변 추상 원리 태그의 교차 메커니즘 전이, 예측 실패 시 학습 알고리즘 자체의 재설계**까지 확장한다.

**심판 현재 기준점은 서브3 72점(기존 `c16467c` 대상)이다.** 이번 커밋의 새 점수와 CI 자격은 재채점 결과를 기다린다.

# Sub4: 계보별 기여도 귀속과 자기개선 실험 우선순위

2026-11-12. This note describes an implemented, editable decision mechanism, **not** a demonstrated performance improvement.

## Problem

The previous compiled metacognitive controller counted a validated multi-component adoption as a full success for every declared intelligence subsystem. This conflates a successful *joint source patch* with separate evidence for its constituent roles, prematurely pushing the search policy toward exploitation. Inherited architecture proposals also need a route back to targeted, frozen evaluator measurements when responsibility remains ambiguous.

## New compiled capability

- `src/engine/rsi_credit_assignment.rs` rechecks the existing independently revalidated generation receipt, model-authored design provenance, actual changed source paths, and accepted source hashes.
- Per verified adoption, split **one unit** of exploratory credit across the grounded roles whose declared modules actually changed. Unchanged named modules receive zero. Retain the original candidate and accepted commit as traceable evidence.
- Separately count single-role source interventions, co-edited interventions, and matched-profile factorial isolations. All are *observational* search evidence; no synthetic causal claims or promotions.
- `rsi_meta_controller::synthesize` now uses fractional attribution as its Bayesian prior instead of blindly assigning a whole win to every component. It separately scores the information value of unresolved attribution and exposes the credit receipts in every alternative.
- The **rebuilt descendant's own** `worker_plan` uses `requiresIsolation` to decide whether to activate the existing source-matched factorial laboratory; the frozen evaluator and adopted-source rules remain untouched.
- The attribution code is registered as an editable Rust engine module so accepted children can redesign the credit and experimentation policy again.

## Intellectual lineage

Hyperagents / DGM-H: self-editable task and meta-agent code, cross-domain improvement (arXiv:2603.19461; facebookresearch/Hyperagents). Mendel Gödel Machine: compare multiple independently measured descendants rather than relying on a single recent winner (arXiv:2608.07645). The new credit layer is a local design combining source-level provenance and uncertainty-driven isolation, not an experimental reproduction of either paper.

## Structural proof boundary

The unit accounting is deterministic, code-level and reviewable. A causal effect requires new matched, randomized interventions and independent confirmation. Compilation, complete-model reproduction, post-adoption speedups, judge score and RSI completion are **not** claimed by this commit. Four focused Rust tests cover joint adoption, unmodified named roles, matched isolation, and invalid independent receipts.
